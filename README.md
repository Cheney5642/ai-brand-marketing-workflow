# AI 品牌营销 Workflow Agent

面向 AI 产品经理作品集展示的品牌营销智能工作流项目。项目计划基于 Coze Workflow 编排营销任务，通过 RAG 知识库提供品牌上下文，使用可版本化的 Prompt 管理机制保障输出一致性，并通过 Evaluation 体系验证 Agent 的质量与稳定性。

> 当前阶段：项目初始化。仓库仅包含目录骨架与项目说明，暂不包含业务代码、真实数据或平台密钥。

## 项目目标

- 展示从业务问题定义到 AI Agent 方案落地的完整产品思路
- 搭建可观察、可评估、可迭代的品牌营销内容生产流程
- 沉淀品牌知识、Prompt 资产和评测数据，降低 Agent 迭代成本
- 为后续 Coze Workflow 演示、案例复盘和作品集讲解提供统一载体

## 核心模块

| 模块 | 作用 | 计划产出 |
| --- | --- | --- |
| Coze Workflow | 编排需求输入、知识检索、内容生成、审核与结果输出 | 工作流导出文件、节点设计、版本记录 |
| RAG 知识库 | 管理品牌资料、产品信息、营销规范和检索策略 | 知识源、切片方案、元数据规范、检索测试 |
| Prompt 管理 | 集中管理不同节点的 Prompt，并记录版本变化 | Prompt 模板、变量说明、版本与变更记录 |
| Evaluation | 从准确性、品牌一致性、安全性和可用性等维度评估效果 | 测试集、评分标准、评测结果与分析报告 |

## 规划中的典型流程

```text
营销需求输入
  → 参数校验与任务识别
  → 品牌知识检索（RAG）
  → 营销策略与内容生成
  → 品牌一致性 / 风险检查
  → 结果输出
  → Evaluation 与迭代记录
```

## 作品集展示重点

后续建议围绕以下主线完善项目：

1. **问题定义**：目标用户、营销场景、现有流程痛点及成功指标。
2. **产品方案**：Agent 边界、Workflow 节点、人工介入点与异常处理策略。
3. **知识工程**：知识来源、清洗切片、元数据设计及召回策略。
4. **Prompt 迭代**：Prompt 版本、设计假设、实验结果与决策依据。
5. **效果验证**：离线测试集、评测 Rubric、基线对比和失败案例复盘。
6. **成果呈现**：演示截图、端到端案例、核心指标和下一阶段规划。

## 建议里程碑

- M1：定义目标用户、核心场景、输入输出与成功指标
- M2：完成品牌知识库样例及 RAG 检索验证
- M3：完成 Coze Workflow 最小可演示版本
- M4：建立 Prompt 版本管理和 Evaluation 基线
